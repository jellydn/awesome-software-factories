# Contributing

Thank you for helping curate Awesome Software Factories.

## What belongs here?

- End-to-end or multi-stage autonomous software delivery systems.
- Factory-building platforms, clearly labeled as such.
- Articles, talks, and videos directly about designing, operating, evaluating, or improving software factories.

Do **not** submit standalone coding assistants, generic agent orchestration libraries, prompt collections, or unrelated AI news.

## Submission checklist

- [ ] Canonical project, article, or video URL.
- [ ] Concise, neutral description.
- [ ] Explain which software factory lifecycle stages are covered.
- [ ] Identify validation, safety, or human-review gates when relevant.
- [ ] Check for duplicate entries and broken links.
- [ ] No unsupported performance claims or affiliate tracking links.

Open a pull request with the new entry in the appropriate section of README.md.
