# Awesome Software Factories

A curated list of **AI-powered software factories**: systems that automate multiple stages of the software delivery lifecycle, from intake and planning through implementation, verification, review, and feedback.

> **Scope:** Software factories, not general-purpose coding assistants, agent frameworks, or isolated multi-agent orchestration tools.

## Software factories

Projects are listed for their **factory workflows**, not merely their ability to generate code.

- [Warp](https://www.warp.dev/) — Agentic development environment with factory workflows and self-improvement practices. See [Warp's factory talk](https://www.youtube.com/watch?v=htM02KMNZnk&t=17730s).
- [OpenAI Symphony](https://openai.com/index/open-source-codex-orchestration-symphony/) — Issue-driven orchestration for autonomous software work.

## Factory-building platforms

These are useful for constructing factory workflows, but should not be confused with complete autonomous software factories.

- **Kody (Kent C. Dodds)** — Agent cloud and automation building blocks; evaluate its factory-specific integrations and end-to-end workflow coverage before reclassifying.

## Inclusion criteria

A listed **software factory** should demonstrate several connected SDLC stages, repeatable autonomous workflows, validation gates, and a clear execution model. Projects that only offer chat, code completion, agent spawning, or generic orchestration do not qualify on their own.

Factory-building platforms are labeled separately. Resources must directly address software factory design, operation, or real-world implementations.
